### Tutorials / Reference Material

- **Unity Learn: Roll-a-ball**  
  Used for the first course exercise and as an introduction to Unity basics such as GameObjects, Rigidbody movement, pickups, camera follow, UI, and building a small playable game.  
  https://learn.unity.com/project/roll-a-ball

- **Unity Learn: Platformer Microgame**  
  Used as general reference for Unity 2D workflow, platformer structure, 2D levels, player movement ideas, and working with a classic 2D platform game template.  
  https://learn.unity.com/project/2d-platformer-template

- **Brackeys: How to make a 2D Game in Unity**  
  Used as inspiration/reference for general 2D Unity game development, including 2D movement, animation, combat, shooting, and game feel.  
  https://www.youtube.com/playlist?list=PLPV2KyIb3jR6TFcFuzI2bB7TMNIIBpKMQ

- **Brackeys: MELEE COMBAT in Unity**  
  Used as reference for melee attack ideas such as attack ranges, detecting hits, and applying damage.  
  https://www.youtube.com/watch?v=sPiVz1k-fEs
